# ThetaVerse — מפרט אפליקציית הדגל

> אפליקציית HTML יחיד (PWA), עברית RTL, מובייל-first, offline-first. התוכן: `daily-practice.md`. תדרים: `sound-frequencies.md`. מחקר מקור: `research/05` + `research/06` + `research/07`.
> **הקובץ החי**: `index.html` בשורש הריפו — מתאים ל-GitHub Pages.

## 0. שפת העיצוב — "יקום זוהר" (הנחיית הדגל)

- **מסך כניסה (Splash) מרשים**: פורטל טבעות מסתובבות (זהב/סגול/ציאן) סביב ליבת אור פנינה נושמת (מוטיב המישור השביעי), לוגו עם גרדיאנט שמר (shimmer), כפתור כניסה עם pulse-glow
- **רקע חי בכל האפליקציה**: שדה כוכבים בקנבס (נצנוץ + סחיפה איטית) + ערפיליות (blobs מטושטשים בסגול-כחול-זהב בתנועת drift איטית)
- **פלטה קוסמית**: חלל עמוק `#05060f→#0f1226`, פנינה `#e8ecf7`, זהב `#e2b96a`, סגול ערפילית `#8b5cf6/#c084fc`, ציאן `#67e8f9`
- **חומריות**: glassmorphism — כרטיסים שקופים-מטושטשים עם מסגרות זוהרות; כרטיס פעיל מקבל glow זהב
- **אנימציות**: fadeUp בכניסת מסכים, breathe בליבות אור, טבעת התקדמות בגרדיאנט זהב→סגול בנגן, גלי אקולייזר במודול התדרים
- כלל: הזוהר משרת רוגע — תנועות איטיות (3–26 שניות), אף פעם לא מהבהב מעל 3Hz (בטיחות אפילפסיה)

## 2. מסכים

### 2.1 היום (מסך הבית)
- ברכה לפי שעה ("בוקר אור, דודו ☀️") + תצוגת הלולאה היומית עם צ'קים
- כרטיס ראשי: התרגול הבא המומלץ לפי שעה (בוקר → עלייה; ערב → תודה/שינה)
- ⚡ כפתור SOS 3 דקות — תמיד נגיש
- הורדת היום (3–5) עם כפתור "כן ✓" לכל אחת
- שורת סטטוס עדינה: "ימי תרגול החודש: 18 🌙"

### 2.2 מדיטציות
- קטלוג 12 המדיטציות (ראה daily-practice.md §2) בכרטיסים עם משך ותמה
- שני מצבים לכל מדיטציה:
  - **מצב מודרך-טקסט**: כרטיסי סקריפט מתחלפים אוטומטית לפי תזמון (עובד 100% אופליין)
  - **מצב TTS**: הקראה ב-Web Speech API (he-IL, קצב 0.75–0.85) עם זיהוי-יכולת ונפילה חזרה לטקסט
- **טיימר חופשי** בסגנון Insight Timer: משך, צלצול פתיחה/סיום, פעמוני ביניים (פעמון "כניסה למישור השביעי" בדקה 4), רקע (גשם/אום/שקט), פריסטים שמורים

### 2.3 יומן חפירה
אשף 8 השלבים (daily-practice.md §4) + רשימה מסוננת + מדף "אמונות שהוחלפו" 🏆

### 2.4 מסע (תוכניות)
- תוכנית 21 יום "המסע למישור השביעי" — מוצגת כמפה של 7 המישורים (3 ימים = מישור)
- תוכנית 30 יום "חיים בתדר תטא"
- כרטיסי תיאוריה של דקה משולבים בכל יום

### 2.4ב תדרים 🌊 (תחום העומק — מיושם)
- **מנוע Web Audio חי** — בלי קבצי אודיו: binaural (StereoPanner ±1), isochronic (LFO→gain), דרוני סולפג'יו עם הרמוניות רכות, קערה מסונתזת (פרשלים לא-הרמוניים), רעש חום/ורוד ואוקיינוס (LFO על lowpass)
- **6 פריסטים**: צלילה לתטא (6Hz+רמפה) · תרגול תטא — הדגל (5.5Hz+528) · שינה עמוקה (2.5Hz+אוקיינוס) · רוגע (8Hz) · ריכוז (10Hz+גשם) · מסע שאמאני (4.5Hz)
- **בורר סולפג'יו**: 9 צ'יפים (174–963Hz) עם דרון + רקע עדין
- כרטיס "מנגן עכשיו" עם טיימר, אקולייזר מונפש, סליידר עוצמה (מיפוי ריבועי), עצירה עם fade
- באנר 🎧 בפריסטים בינאורליים + "אין לי אוזניות" → המרה אוטומטית ל-isochronic
- שרשרת בטיחות: DynamicsCompressor כמגביל, אזהרות נהיגה/טינטון, פעימת פתיחה בקערה 432
- דקות ההאזנה נספרות בסטטיסטיקות ("דקות בתדר")
- פירוט מלא + קוד: `sound-frequencies.md` ו-`research/07-audio-engineering.md`

### 2.5 סטטיסטיקות
סך דקות בתטא · מסעות למישור השביעי · הורדות שאושרו · אמונות שהוחלפו · לוח מצב-רוח חודשי (לפני/אחרי)

### 2.6 הגדרות
לשון פנייה (זכר/נקבה/ניטרלי) · תזכורות בוקר/ערב (ברירת מחדל: כבויות) · קול TTS וקצב · ערכת נושא (כהה כברירת מחדל) · ייצוא/ייבוא נתונים · אודות + דיסקליימרים

## 3. מכניקות ליבה

### 3.1 Check-in / Check-out
לפני תרגול: הקשה אחת — 5 אימוג'י מצב-רוח + סליידר "תדר" 1–10 (אופציונלי). אחרי: אותו דבר + הצגת הדלתא ("עלית מ-4 ל-7 ✨"). זו מכניקת ההוכחה-האישית החזקה ביותר.

### 3.2 רצף עדין (Gentle Streak)
- כל תרגול ≥ דקה נספר (כולל הורדה אחת)
- "יום חסד" אוטומטי אחד בשבוע
- שבירת רצף = אירוע בר-תיקון: חזרה של יומיים רצופים משחזרת ("חזרת! ההתמדה שלך נשמרת")
- מדד ראשי: **ימי תרגול מצטברים בחודש** (לא רצף עוקב)
- יעד שבועי: 5/7 = "שבוע מלא"

### 3.3 אבני דרך
7 / 21 / 30 / 100 / 365 ימי תרגול · מדיטציה מס' 50 · אמונה מוחלפת מס' 10.
חגיגה: אנימציית לוטוס/אור + **הורדה מיוחדת כפרס** (הפרס הוא תוכן — on-brand).

### 3.4 תזכורות
התראות מקומיות בוקר/ערב שהמשתמש קובע; ניסוח רך ("3 דקות של אור לפני השינה? 🌙"); בלי דחיפות אשמה.

- **מסך תרגול**: full-screen, כרום מוסתר, טבעת התקדמות מעגלית, זמן ענק במרכז, השהיה בהקשה

## 5. טכני

- **קובץ HTML יחיד**, יעד < 1.5MB; פונטים כ-woff2 data-URI (subset עברית); פעמונים ב-Web Audio API (סינתזה או base64 זעיר)
- **PWA**: manifest inline (base64) + service worker דרך Blob URL, או "הוסף למסך הבית" עם `apple-mobile-web-app-capable`
- **Wake lock** בזמן תרגול (`navigator.wakeLock`); טריק `<audio>` שקט ללולאת רקע ב-iOS
- **TTS**: `speechSynthesis` עם `getVoices()` מסונן ל-`he`; iOS = Carmit, Android = Google TTS; זיהוי-יכולת + נפילה לטקסט (Firefox Android בלי קולות)
- **אחסון**: מפתח JSON אחד ב-localStorage עם שדה `schemaVersion`:
